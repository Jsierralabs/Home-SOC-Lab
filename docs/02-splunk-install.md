# Splunk Enterprise Installation

## Objective
Deploy a local SIEM using the Splunk Enterprise Developer License.

## Hardware
- Windows 11
- Ryzen 5 3600
- 32 GB RAM
- 1 TB SSD
- 2 TB HDD

## Completed
- Installed Splunk Enterprise
- Applied 10 GB Developer License
- Verified web interface
- Confirmed service startup

## Lessons Learned
- Developer Program provides a Splunk Enterprise license, not an automatic Splunk Cloud instance.
- Local installation provides more control for a home lab.
